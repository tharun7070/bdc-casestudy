# Real dataset goes here

Download the **events.csv** file from the Retailrocket Kaggle dataset using:

```bash
python download_dataset.py
```

Expected file: `data/events.csv`

Do not commit the raw dataset to GitHub. The dataset is approximately 2.76 million real-world anonymized events and is distributed under CC BY-NC-SA 4.0. Link to the original Kaggle page instead.
